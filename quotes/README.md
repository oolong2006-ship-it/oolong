# ⚖️ مُقارِن — منصة مقارنة عروض الأسعار الاحترافية

تطبيق ويب **سحابي خفيف** لمقارنة عروض أسعار الموردين: ارفع عروض الأسعار بصيغة **PDF** واحصل خلال ثوانٍ على دراسة احترافية واضحة تحدد **أفضل سعر لكل صنف من جميع الموردين** و**أفضل مورد إجمالاً** مع حساب الوفورات والتوصيات.

## ✨ المزايا

| الميزة | الوصف |
|---|---|
| 📄 **رفع PDF مباشر** | ملف لكل مورد — سحب وإفلات، وعدة ملفات دفعة واحدة |
| 🤖 **استخراج ذكي (Claude)** | يقرأ العروض النصية والممسوحة ضوئيًا ويستخرج المورد والأصناف والكميات والأسعار والضريبة والشروط تلقائيًا |
| ⚡ **محلل محلي احتياطي** | يعمل بدون مفتاح API لملفات PDF النصية (عبر pdf.js) |
| ✏️ **مراجعة قابلة للتعديل** | دقّق وعدّل أي بيانات مستخرجة قبل التحليل، وأضف موردين أو أصنافًا يدويًا |
| 🔗 **مطابقة ذكية للأصناف** | تطبيع عربي (الهمزات، التاء المربوطة، التشكيل…) وتشابه ضبابي لمطابقة نفس الصنف بين الموردين ولو اختلفت الصياغة |
| ⚖️ **مصفوفة مقارنة** | سعر كل صنف لدى كل مورد مع تظليل الأفضل (أخضر) والأعلى (أحمر) ونسبة الارتفاع عن أفضل سعر |
| 🏆 **أفضل مورد إجمالاً** | ترتيب الموردين حسب الإجمالي والتغطية وعدد الأصناف الفائزة ومتوسط الانحراف السعري |
| 🧺 **السلة المثلى** | لو رسّيت كل صنف على صاحب أفضل سعر: الإجمالي، توزيع الترسية على الموردين، والوفر مقارنة بأفضل مورد واحد |
| 📌 **توصيات تلقائية** | خلاصة مهنية: أين تفاوض؟ هل تقسّم الترسية؟ أصناف بفروق كبيرة، وشروط الموردين |
| 📤 **تصدير** | تقرير طباعة/PDF منسق + تصدير CSV + حفظ المقارنات محليًا |

## 🚀 التشغيل والنشر

التطبيق ثابت بالكامل (HTML/CSS/JS) وجاهز كمشروع مستقل — **لنشره برابط خاص على Vercel اتبع [دليل النشر DEPLOY.md](DEPLOY.md)** (أقل من دقيقتين، بدون أي أوامر بناء).

للتشغيل محليًا:

```bash
cd quotes
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

### تفعيل الاستخراج الذكي (يُنصح به)

1. احصل على مفتاح Claude API من [platform.claude.com](https://platform.claude.com).
2. من **⚙️ الإعدادات** أدخل المفتاح واحفظ.
3. يُحفظ المفتاح على جهازك فقط (localStorage) وتُرسل الملفات مباشرة إلى خدمة Claude — **لا يوجد خادم وسيط**.

بدون مفتاح، يعمل **المحلل المحلي** على ملفات PDF النصية (لا يدعم الملفات الممسوحة ضوئيًا).

## 🧭 خطوات الاستخدام

1. **رفع العروض** — اسحب ملفات PDF (ملف لكل مورد). يُستخرج كل عرض ويظهر عدد الأصناف واسم المورد (قابل للتعديل).
2. **مراجعة البيانات** — دقّق الأصناف والكميات والأسعار وعدّل ما يلزم. كلما تطابقت مسميات الأصناف بين الموردين كانت المقارنة أدق.
3. **التحليل والمقارنة** — بطاقات ملخص، توصيات، ترتيب الموردين، مصفوفة المقارنة، والسلة المثلى. اطبع التقرير أو صدّره CSV أو احفظ المقارنة.

## 🧱 البنية التقنية

- HTML5 + CSS3 (RTL عربي متجاوب + أنماط طباعة) + JavaScript خالص — بدون بناء أو تبعيات تثبيت.
- `js/util.js` — تطبيع النص العربي، التشابه الضبابي، تنسيق الأرقام.
- `js/extract.js` — الاستخراج الذكي (Claude API — نموذج `claude-opus-4-8` بإرسال PDF كمستند) + المحلل المحلي (pdf.js).
- `js/analyze.js` — مطابقة الأصناف، مصفوفة المقارنة، ترتيب الموردين، السلة المثلى، التوصيات.
- `js/app.js` — الواجهة والحالة والحفظ والتصدير.

## 🔒 الخصوصية

- جميع البيانات والمقارنات المحفوظة تبقى على جهازك (localStorage).
- لا يُرفع أي ملف إلى خادم وسيط؛ عند تفعيل الاستخراج الذكي تُرسل الملفات مباشرة من متصفحك إلى خدمة Claude API فقط.

# 🧭 مَورِد — منصة اكتشاف الموردين ومقارنة الأسعار عبر الإنترنت

منصة سحابية تساعد **مدير المشتريات**: تُدخِل اسم صنف واحد، فيبحث النظام في **المواقع والمتاجر عبر الإنترنت** ويجمع **كل الموردين المحتملين** الذين يبيعون هذا المنتج **بالضبط**، ثم يقارن أسعارهم وجودتهم ومدة توريدهم في واجهة قرار واحدة، مع **تنبيهات ذكية** عند تغيّر الأسعار أو ظهور موردين جدد.

> الفكرة الجوهرية: بدلاً من قاعدة بيانات موردين ثابتة تُدخَل يدويًا، يبحث «مَورِد» **حيًّا في الإنترنت** لحظة الطلب باستخدام أداة البحث على الويب في نموذج **Claude**، فيكتشف موردين لم تكن تعرفهم مسبقًا.

---

## ✨ كيف يلبّي المتطلبات الستة

| المتطلب | التنفيذ في «مَورِد» |
|---|---|
| **1. قاعدة بيانات الموردين والمنتجات** | مصدر البيانات هو **الإنترنت الحي** لا جدول ثابت: لكل بحث يبني النظام سجلًا منظّمًا لكل مورد (الاسم، المنتج المطابق، السعر والعملة، منطقة التوريد، الرابط، التوفر، مدة التوريد، تقييم الجودة، مستوى التطابق). الأصناف المتابَعة تُحفَظ محليًا كـ«لقطات» لرصد التغيّر. |
| **2. آلية البحث المتقدمة** | استرجاع الموردين لصنف محدد عبر عدة استعلامات بحث (عربية/إنجليزية) + **تصفية فورية** حسب السعر الأقصى، والحد الأدنى للتقييم، وأقصى مدة توريد، والمنطقة، ومستوى التطابق، مع **ترتيب** حسب السعر/التقييم/السرعة/أفضل قيمة. |
| **3. مقارنة الأسعار والعروض** | جدول مقارنة كامل + **بطاقات قرار** فورية: أفضل سعر، أعلى تقييم، أسرع توريد، **أفضل قيمة** (مؤشر مركّب من السعر والجودة والسرعة)، ووسم «الأرخص/أفضل قيمة» على الصفوف، وتصدير **CSV**. |
| **4. التحديث التلقائي للبيانات** | زر تحديث لكل صنف، و«تحديث الكل» للأصناف المتابَعة؛ يُعاد البحث حيًّا ويُقارَن بالأساس المحفوظ لاكتشاف تغيّرات الأسعار وظهور/اختفاء الموردين. |
| **5. الإشعارات والتنبيهات الذكية** | يولّد النظام تنبيهات عند **انخفاض سعر**، أو **ظهور موردين جدد**، أو **تحقّق أفضل سعر جديد**، مع جرس تنبيهات وعدّاد غير المقروء، ودعم **إشعارات المتصفح**. |
| **6. واجهة سهلة الاستخدام** | واجهة عربية RTL متجاوبة وبديهية: شريط بحث واحد واضح، بطاقات ملخّص، فلاتر منسدلة، جدول مرتّب، ونوافذ خفيفة للإعدادات والتنبيهات. |

## 🚀 التشغيل

منصة ويب ثابتة (Static) تعمل مباشرة — لا حاجة لخادم خلفي:

```bash
# من جذر المستودع
python3 -m http.server 8000
# ثم افتح: http://localhost:8000/mawrid/
```

أو افتح `mawrid/index.html` في المتصفح مباشرة.

### الوضعان
- **الوضع التجريبي (افتراضي):** بدون مفتاح، يعرض بيانات موردين توضيحية لاستكشاف كامل الواجهة والمقارنة والتنبيهات.
- **الوضع المتصل (بحث حي):** من **⚙️ الإعدادات** أدخل مفتاح **Claude API**، فيبدأ البحث الحقيقي عبر الإنترنت. يُحفظ المفتاح **محليًا على جهازك فقط**، وتُرسَل الطلبات مباشرةً إلى خدمة Claude.

---

## 🧠 كيف يعمل البحث الحي؟

يستدعي `js/ai.js` نموذج **Claude (`claude-opus-4-8`)** مزوّدًا بأداة **البحث على الويب** (`web_search_20260209`) التي تنفّذ عدة عمليات بحث حقيقية على الإنترنت وتصفّي النتائج، ثم يُطلَب من النموذج إعادة قائمة الموردين المطابقين بصيغة **JSON** منظّمة. يقوم التطبيق بتطبيع النتائج وعرضها ومقارنتها ورصد تغيّراتها.

- تُوجَّه التعليمات لإدراج الموردين الذين يعرضون **المنتج المطلوب بالضبط** فقط، مع تحديد **مستوى التطابق** عند الشك، وعدم اختراع الأسعار.
- يغطي البحث مصادر **محلية وإقليمية وعالمية**، ويمكن تفضيل منطقة/عملة معيّنة من الإعدادات.

---

## 🧱 البنية التقنية

بلا أي مكتبات خارجية — HTML5 + CSS3 (RTL عربي متجاوب) + JavaScript خالص:

- `mawrid/index.html` — هيكل الصفحة والشريط العلوي والنوافذ.
- `mawrid/css/style.css` — التصميم العربي المتجاوب.
- `mawrid/js/util.js` — أدوات مساعدة (DOM، تنسيق، تخزين محلي).
- `mawrid/js/ai.js` — محرك البحث عن الموردين عبر Claude + أداة البحث على الويب، ومحرك تجريبي احتياطي.
- `mawrid/js/app.js` — الحالة والواجهة: البحث، المقارنة، الفلاتر، المتابعة، التحديث التلقائي، والتنبيهات.

### ☁️ ملاحظة النشر السحابي
لأن التطبيق ثابت بالكامل، يمكن نشره **أونلاين** على أي استضافة ثابتة (GitHub Pages / Vercel / Netlify) دون بنية خلفية. للاستخدام المؤسسي مع إخفاء مفتاح API عن المتصفح، يُوصى بإضافة **بوابة خادم رقيقة (proxy)** تمرّر الطلبات إلى Claude وتحفظ المفتاح في الخادم — وهي إضافة مستقبلية لا تغيّر الواجهة.

## 🔒 الخصوصية
لا يُرسَل مفتاح API إلى أي طرف عدا خدمة Claude مباشرةً، وتُحفَظ الإعدادات والأصناف المتابَعة والتنبيهات في **التخزين المحلي** على جهاز المستخدم فقط.

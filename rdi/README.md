# RDI — تحليل ربحية المطاعم على التوصيل

أداة استشارية تحلّل ربحية أصناف المطعم على منصات التوصيل السعودية (هنقرستيشن، جاهز، كيتا، مرسول)
وتولّد تقريراً احترافياً بالمشاكل والتوصيات ومقترحات العروض.

> **المرحلة 1:** تحليل مطعم واحد + تقرير + تصدير + حفظ محلي (localStorage).

## التشغيل على جهازك

تحتاج [Node.js](https://nodejs.org) (نسخة 18 أو أحدث). ثم من داخل مجلد `rdi`:

```bash
npm install      # تثبيت المكتبات (مرة واحدة)
npm run dev      # تشغيل التطبيق محلياً
```

افتح الرابط الظاهر (عادة http://localhost:5173) في المتصفح.

أوامر أخرى:

```bash
npm test         # تشغيل اختبارات المنطق المالي
npm run build    # بناء نسخة جاهزة للنشر (مجلد dist)
```

## خطوات الاستخدام

1. **البيانات:** أدخل اسم المطعم والفرع، ثم حمّل قالب الإكسل واملأه وارفعه.
2. **المنصات:** عدّل العمولات حسب عقد المطعم، واضبط نسبة الرفع والخصم ومفتاح الضريبة.
3. **التقرير:** اطّلع على التحليل الكامل، وصدّره PDF أو Word.

## بنية الكود

```
src/
  lib/
    finance.js       # ⭐ نواة المنطق المالي (الطبقات السبع) — مغطّى باختبارات
    finance.test.js  # اختبارات التحقق من صحة الحسابات
    excel.js         # قراءة الإكسل + القالب + التحقق
    export.js        # تصدير PDF و Word
    storage.js       # الحفظ المحلي (يُستبدل بقاعدة بيانات لاحقاً)
    defaults.js      # المنصات والإعدادات الافتراضية
    sanitize.js      # تهريب النصوص (حماية XSS)
    format.js        # تنسيق الأرقام والعملة
  components/
    RestaurantForm.jsx
    PlatformSettings.jsx
    Charts.jsx
    Report.jsx
  App.jsx            # ربط الخطوات والحالة
```

## التقنيات

React + Vite + Tailwind CSS (دعم RTL كامل) · SheetJS لقراءة الإكسل · Recharts للرسوم · Vitest للاختبارات.
